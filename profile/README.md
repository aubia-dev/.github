The simplest way to miss a mistake is to be the one who wrote it. It holds for agents too: Claude misses details Codex catches on the first pass, and Codex pushes an implementation where Claude would have challenged the approach. Aubia is the layer above Claude Code, Codex CLI and Mistral that hands them the diff until they agree, and leaves the call to you.

## What Aubia adds to your AI agents

- **Automatic cross-review**: one agent implements, an agent from another model family reviews. They exchange the diff until convergence, over the number of iterations you set.
- **Opinions to Executable Plan Mode**: submit a technical decision to several models at once. Each argues its position, Aubia synthesizes the convergences, isolates the disagreements, and generates an arbitrated plan you can edit and run.
- **BYOK**: your contracts with Anthropic, OpenAI and Mistral stay yours. Keys encrypted in your OS keychain, no token reselling, no vendor lock-in.
- **Local-first desktop**: agents run locally, each in its own isolated git worktree. Your code never leaves your machine.
